x402-carbon

Grid carbon intensity now and best-window scheduling — keyless live data for green agents

No account, no API key, no subscription. Call a paid route without payment and you get HTTP 402 plus a machine-readable challenge listing what it costs and how to pay — USDC on Base (EVM) or Solana. Retry with an X-PAYMENT header and the same request returns the artifact.

Routes

MethodPathPriceReturns
GET /now $0.001 Current GB grid carbon intensity and generation mix
POST /best-window $0.002 The lowest-carbon window to run a deferrable job in the next 48 hours
GET / free Service metadata, live prices, and active payment rails
GET /health free Liveness probe
GET /.well-known/x402 free x402 discovery manifest

Call it

npm i x402-fetch viem

import { wrapFetchWithPayment } from "x402-fetch";
const pay = wrapFetchWithPayment(fetch, wallet);
const res = await pay("http://localhost:4025/health");
